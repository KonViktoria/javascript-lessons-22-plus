# JavaScript: уроки с 22-го

Учебные примеры и домашние задания по JavaScript.

## Содержание

- Урок 22 — файлы `task01.js`, `task02.js`, `task03.js`, `taks04.js`, `task05.js` в корне: запросы погоды через Fetch и Axios.
- `lesson23/` — объекты, работа с Gemini API и домашнее задание `HW_23/`.
- `lesson24/` — ввод данных в консоли и сохранение продуктов в JSON.
- `lesson26/` — работа с API, проверка данных и домашнее задание `HW_26/`.

## Запуск

Установите Node.js и зависимости:

```sh
npm ci
```

Запускайте нужный файл из корня проекта, например:

```sh
node task05.js
node lesson26/HW_26/task01.js
```

Для примеров с Gemini задайте переменную окружения `GEMINI_API_KEY`.
Примерам с внешними API требуется подключение к интернету.

`node_modules/`, локальные файлы `.env`, логи и создаваемые упражнением
файлы `fridge.json` и `fridge.csv` исключены из Git.

Это учебные материалы: некоторые задания содержат незавершённые решения.
